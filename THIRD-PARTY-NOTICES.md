# Third-party references

This distribution contains original workflow guidance and helper scripts, with links to upstream documentation. No upstream application code, manuals, executables, font files or game assets are copied into this package. Tool names belong to their respective owners; this is not an official Unity, Blender or PhotoCraft distribution.

| Dependency | Included here | Terms to review when obtaining it |
|---|---|---|
| Unity Editor, Hub, CLI, Pipeline | No | [Unity legal terms](https://unity.com/legal) and the selected package's notices |
| Blender | No | [Blender licensing](https://www.blender.org/about/license/) |
| PhotoCraft 0.17.0 | No | [Pinned repository](https://github.com/storytold/photocraft/tree/v0.17.0), its LICENSE-MIT, LICENSE-APACHE, NOTICE, ATTRIBUTION.md and bundled font notices |
| Python / PowerShell | No | Their installed distributions' licenses |

The PhotoCraft packaging source describes included notices. This is not a license audit of the release binary. Keep the complete upstream archive contents when installing locally. Before rebundling any tool, separately verify redistribution requirements. For each game asset, record author, source, exact license, modifications and any required credit in that game's asset register; unknown rights block shipping that asset.
