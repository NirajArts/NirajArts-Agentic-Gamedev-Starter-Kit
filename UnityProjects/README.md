# Independent Unity projects

Create a real project here through the installed Unity Hub or verified Unity CLI when the user requests one. Use one direct child folder per game, such as `UnityProjects/YourChosenName`. This README is a placeholder, not a Unity project.

After the Editor has initialized and saved project settings, register and select the project using [the state helper](../docs/project-state.md). Keep source art inside that game (for example `SourceArt/`), imported assets under `Assets/`, and its game-specific design in `Docs/`. These folders are conventions to apply as needed, not prebuilt content.
